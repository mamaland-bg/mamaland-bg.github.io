# Как да влизаш в сайта и пишеш статии

Кратко ръководство за д-р Мерилин Иванова.

Няма нужда да разбираш как работи сайтът отвътре — просто следвай стъпките.

---

## Еднократна подготовка (само първия път)

### Стъпка 1 — Създай си GitHub акаунт

GitHub е услугата, през която влизаш в сайта — нещо като имейл акаунт, но за код.

1. Отвори [github.com/signup](https://github.com/signup)
2. Въведи имейл, парola и потребителско име (може да е каквото искаш, напр. `merilin-mamaland`)
3. Потвърди имейла си, когато GitHub ти изпрати линк

**Запиши си някъде потребителското име и паролата** — ще ти трябват всеки път.

### Стъпка 2 — Приеми поканата

Боян ще те добави като сътрудник в проекта. Ще получиш имейл от GitHub с покана — отвори го и натисни **"Accept invitation"**.

Ако не си получила покана, кажи на Боян твоето GitHub потребителско име, за да те добави.

---

## Всеки път, когато искаш да пишеш

### Стъпка 1 — Отвори страницата за вход

Иди на:

**https://mamaland.bg/admin**

> ⚠️ Използвай точно този адрес (без "www" отпред). В момента версията с "www" има технически проблем и браузърът ще покаже предупреждение — това ще се оправи скоро, но дотогава ползвай адреса по-горе.

Препоръчвам да го запазиш в отметките (bookmark) на браузъра си, за да не го търсиш всеки път.

### Стъпка 2 — Влез с GitHub

1. Натисни бутона **"Sign in with GitHub"** (или "Login with GitHub")
2. Ще се отвори страница на GitHub — въведи твоето потребителско име и парola
3. Ако GitHub попита дали да разреши достъп ("Authorize") — натисни зелено бутона за одобрение

### Стъпка 3 — Готово

Ще влезеш в администрацията на сайта, откъдето можеш да:

- Пишеш нови **статии** (Статии → New Статия)
- Добавяш **семинари**
- Редактираш текстовете на **началната страница** и **контактите** (Настройки на сайта)

Когато натиснеш **Save/Публикувай**, промените се качват автоматично на сайта до около **1 минута**.

---

## Чернова vs. Публикувана

Всяка статия и семинар има поле **"Статус"**:

- **✏️ Чернова** — не се вижда на сайта, можеш да я пишеш на спокойствие
- **✅ Публикувана** — вижда се веднага на mamaland.bg

Смени статуса на "Публикувана", когато си готова текстът да излезе.

## Ако нещо се обърка

| Проблем | Какво да направиш |
|---|---|
| Забравена парола | На страницата за вход в GitHub натисни "Forgot password" |
| Пише "Not authorized" | Кажи на Боян — трябва да те добави отново като сътрудник |
| Не виждаш промяната на сайта | Изчакай 1–2 минути и презареди страницата (Ctrl/Cmd + R) |
| Друг проблем | Пиши на Боян |
